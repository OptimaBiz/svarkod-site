# СВАРКОД

Современное отраслевое медиа и рабочая система знаний о сварке, промышленной безопасности и регулировании.

## Стек

- Astro 5, статическая сборка;
- Content Collections для реального редакционного контента;
- отдельный удаляемый demo-layer;
- клиентский поиск без внешней БД;
- GitHub Actions CI и Pages deployment;
- формы и будущий сервис рейтингов отделены от публичного статического сайта.

## Демо-режим

Весь вымышленный контент хранится отдельно в `src/demo-data/*.json`. Шаблоны и production-content не зависят от наличия demo-файлов.

Чтобы удалить **все демонстрационные статьи, документы, организации, события, рейтинги и форумные темы одной командой**:

```bash
pnpm demo:clean
```

После команды остаётся чистая рабочая оболочка: маршруты, дизайн, фильтры, поиск, пустые состояния, редакционные методики и инфраструктура.

Демо-данные нельзя переносить в боевой контент без редакционной проверки.

## Реальный контент

- `src/content/articles` — статьи;
- `src/content/documents` — редакционные документы и методики;
- `src/content/organizations` — проверенные профили;
- `src/content/events` — проверенные события и нормативные даты.

## Команды

```bash
pnpm install
pnpm dev
pnpm build
pnpm demo:clean
```

## Формы

Формы отключены, пока не задан `PUBLIC_FORMS_ENDPOINT`.

## Деплой

`main` автоматически собирается и публикуется через GitHub Pages. Для project Pages workflow получает реальный `base_path` и готовит внутренние ссылки под него; основной production-домен проекта остаётся `https://svarkod.ru`.
