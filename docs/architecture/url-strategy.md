# URL strategy

Канонические семейства: `/edition/`, `/requirements/`, `/certification/`, `/practice/`, `/registry/`, `/ratings/`, `/community/`.

Старые адреса `/news/`, `/norms/`, `/documents/`, `/organizations/`, `/events/`, `/forum/` сохраняются как точки совместимости. После миграции хостинга для устаревших дублей допускаются постоянные 301-редиректы.
