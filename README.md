# СВАРКОД 2.0

Исходный код отраслевой системы «СВАРКОД — Код сварочной отрасли».

СВАРКОД 2.0 объединяет редакционные материалы, нормативную навигацию, документы, технологии, каталог организаций, отраслевой календарь и прозрачный контур рейтингов.

## Архитектура

- Astro 5, статическая сборка;
- Content Collections для статей, документов, организаций и событий;
- единый клиентский поиск без внешней поисковой БД;
- генерируемые sitemap и RSS;
- форум, формы и будущий сервис рейтингов отделены от статического сайта;
- CI и GitHub Pages deployment workflows.

## Контент

`src/content/articles` — редакционные материалы.

`src/content/documents` — карточки документов и редакционные методики.

`src/content/organizations` — проверяемые профили организаций. В публичном каталоге не следует создавать вымышленные организации ради демонстрации.

`src/content/events` — проверенные события и нормативные даты. Даты должны подтверждаться первичным источником.

## Формы

Формы отключены, пока не задан `PUBLIC_FORMS_ENDPOINT`. Это намеренная блокировка: статический сайт не должен собирать персональные данные до подключения защищённого контура и утверждения политики обработки данных.

## Локальный запуск

```sh
pnpm install
pnpm dev
```

## Сборка

```sh
pnpm build
```

Статическая версия создаётся в `dist`.

## Проверка

На каждый push в `main` GitHub Actions запускает frozen install и статическую сборку.

## Деплой

`.github/workflows/deploy-pages.yml` собирает `dist` и публикует артефакт через официальный GitHub Pages Actions flow. Для фактического GitHub Pages deployment в настройках репозитория Pages должен быть выбран источник **GitHub Actions**.

Основной production-домен проекта остаётся `https://svarkod.ru`. Привязка домена и DNS выполняются на стороне GitHub Pages/хостинга и DNS-провайдера.
