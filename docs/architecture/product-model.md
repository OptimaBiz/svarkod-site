# Product model

СВАРКОД проектируется как четыре связанных слоя: независимое отраслевое издание, система знаний, проверяемые отраслевые данные и профессиональное сообщество.

Публичная навигация строится не по типам файлов, а по задачам пользователя: понять изменение, определить применимость, пройти аттестацию, решить производственную задачу, проверить запись, получить профессиональное обсуждение.
