# СВАРКОД

Исходный код отраслевого интернет-издания «СВАРКОД — Код сварочной отрасли».

Основные темы проекта: сварка на опасных производственных объектах, промышленная безопасность, нормативное регулирование и технологии сварки.

## Архитектура

- Astro, статическая сборка.
- Редакционные статьи и карточки документов — Astro Content Collections в `src/content`.
- Поиск — локальный индекс опубликованного контента без серверного хранилища.
- `sitemap.xml` генерируется из маршрутов и контент-коллекций.
- Формы отправляются только во внешний защищённый контур через `PUBLIC_FORMS_ENDPOINT`; без него поля и кнопки отключены.
- Форум остаётся отдельным контуром на `forum.svarkod.ru`.

## Локальный запуск

```sh
pnpm install
pnpm dev
```

## Сборка

```sh
pnpm build
```

Статическая версия сайта создаётся в каталоге `dist`.

## Формы

Скопируйте `.env.example` в `.env` и задайте `PUBLIC_FORMS_ENDPOINT` только после подготовки защищённого обработчика и утверждения документов по обработке персональных данных.

## CI

GitHub Actions запускает `pnpm install --frozen-lockfile` и `pnpm build` для `main` и pull request.
