# СВАРКОД

СВАРКОД — отраслевое сетевое издание и рабочая система знаний о сварке, аттестации и промышленной безопасности.

## Продуктовая модель

Публичный контур строится вокруг шести задач пользователя:

1. **Издание** — новости, аналитика, объяснения, расследования, интервью.
2. **Требования** — первоисточники, атомарные требования, сроки, сравнение редакций.
3. **Аттестация** — маршруты для персонала и производства, документы, сроки, проверка сведений.
4. **Практика** — процессы, качество, дефекты, НК, оборудование, материалы, безопасность.
5. **Реестры и рейтинги** — проверяемые профили, источники, выпуски рейтингов, апелляции.
6. **Сообщество** — экспертные ответы, события и отдельный форумный контур.

## Архитектурные границы

- `svarkod.ru` — статический публичный сайт на Astro;
- `forum.svarkod.ru` — отдельный форумный контур;
- динамические голосования, апелляции, формы и аккаунты не хранятся в Astro Content Collections;
- редакционные карточки всегда отделяют официальный источник, редакционную интерпретацию, пользовательский контент и коммерческое размещение.

## Контент

- `src/content/articles` — редакционные публикации;
- `src/content/documents` — карточки документов и методик;
- `src/content/requirements` — атомарные требования;
- `src/content/qualification-paths` — маршруты аттестации и квалификации;
- `src/content/organizations` — проверяемые профили организаций;
- `src/content/events` — события и нормативные даты;
- `src/content/rating-editions` — версии опубликованных рейтингов.

## Команды

```bash
pnpm install
pnpm validate
pnpm build
pnpm dev
```

`main` публикуется через GitHub Pages workflow. Формы остаются отключёнными до подключения защищённого обработчика через `PUBLIC_FORMS_ENDPOINT`.
