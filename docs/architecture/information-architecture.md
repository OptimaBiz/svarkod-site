# Information architecture

Верхний уровень: Издание, Требования, Аттестация, Практика, Реестры и рейтинги, Сообщество.

Каждая сущность должна иметь один канонический URL и связи с источниками. Старые публичные URL сохраняются как совместимые точки входа и получают canonical на новую структуру там, где это уместно.
